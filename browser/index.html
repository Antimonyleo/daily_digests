More about computing

Choose a mode, then Apply and reload. Finish or stop an active brew first. Acceleration speeds new text comparisons; fetching and other work still use the CPU. Cached comparisons need no acceleration, and the existing digest does not change when you switch.

CPU and GPU can select different borderline papers. Switching modes can require recalculating saved text comparisons.

First-time GPU setup downloads a separate model export, about 133 MB.

Brewing uses processor and memory and can increase heat, fan noise and battery use. Thousands of new articles may take 20 minutes or more on one CPU core. GPU support is experimental while hardware performance is being verified across devices. CPU fallback keeps the same ranking rules.

Companion (optional)

An optional helper on your computer connects this page to your Claude or Codex login, email and scheduled brews. Skip it to read in the browser.

  1. Install the local DailyDigest app on your computer. For Claude or Codex summaries, sign in to its CLI there.
  2. Start the helper and leave it running: dd companion --allowed-origin https://antimonyleo.github.io
  3. Copy the server URL and token from its startup message into the fields below. The message also gives the token file location for later use.

The helper receives selected paper metadata and a short research profile for summaries. Send browser state separately for scheduled brews; this transfers your profile, feedback and history. Credentials are excluded unless you choose to include them.
