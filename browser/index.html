Companion

A companion can provide model summaries, email, inbound reading and optional state transfer. Connect only to a server you trust. Each action below is explicit.

Install DailyDigest on the companion computer, then run:

dd companion --allowed-origin https://antimonyleo.github.io

The command prints the location of your reusable private token. Your Claude or Codex login must be on that computer.

No companion configured.

Select a provider supported by your companion in Settings to use its summaries during a brew. Provider credentials stay on the companion.

For scheduled brews, send browser state once and keep the companion running. Restore companion state to retrieve its latest digest.
