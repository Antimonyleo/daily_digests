More about computing

Choose a mode, then Apply and reload; finish or stop any brew first. Only comparing new papers gets faster: fetching still uses the CPU, saved comparisons are reused, and your current digest stays as it is.

GPU mode downloads a separate model once, about 133 MB. It can pick slightly different borderline papers than CPU mode, and switching may recompute saved comparisons. If the GPU fails, DailyDigest falls back to the CPU with the same ranking rules.

Brewing works the processor hard and can raise heat, fan noise and battery use. Thousands of new papers can take 20 minutes or more on one CPU core.

Companion (optional)

A web page can’t run programs on your computer, send email or keep brewing after you close it. The Companion is a small helper you run on your own computer that does these jobs for this page:

  • summaries with your signed-in Claude Code or Codex, or an API key kept on your computer;
  • emailing your digest, and reading email replies as ratings;
  • brewing on a schedule while this browser is closed.

It is not remote access. It listens only on your computer and answers only this site, with your token. You don’t need it to read here, and if you read in the DailyDigest app on your computer rather than on this website, you don’t need it at all.

  1. Install the DailyDigest app on your computer. For Claude Code or Codex, sign in to claude or codex there; for email, add RESEND_API_KEY, DIGEST_FROM and DIGEST_TO to the app’s .env file.
  2. Start the helper and leave it running: dd companion --allowed-origin https://antimonyleo.github.io For scheduled brews, add --state-dir with a folder for its copy, and --schedule.
  3. It prints an address (usually http://127.0.0.1:8768) and the path of a token file. Enter the address below, and paste the token from that file.

For summaries, the Companion receives the same paper details and short profile any summary provider gets. Scheduled brews work on a copy of your reading desk that you send it; credentials stay out unless you include them. Connect only to a helper you trust.

Other sites under this github.io address share this browser’s storage, including any saved credentials. Keeping API keys on the Companion avoids that.
