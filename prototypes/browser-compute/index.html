Can your browser brew a research digest?

This prototype runs a local embedding model and existing Python ranking rules in your browser. It compares the result with a prepared Python reference. All papers and interests are development fixtures; this is a runtime-parity experiment, not a claim of improved recommendations.

The first load includes a 66 MB model plus Python/WebAssembly dependencies. The serving process only supplies files. No live papers, personal profile, ratings, or database are loaded.
